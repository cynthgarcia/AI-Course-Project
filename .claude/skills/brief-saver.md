# Skill: Brief Saver

**Purpose:** Assemble all 7 sections of the Weekly Investment Brief into a formatted markdown document and save it to `Weekly Brief Updates/brief-YYYY-MM-DD.md`.

---

## Inputs

When this skill is invoked, you will receive:
1. **Section 1 output** — Market analysis
2. **Section 2 output** — Geopolitical and macro context
3. **Section 3 output** — Trends and risk
4. **Section 4 output** — Stock recommendations
5. **Section 5 output** — When to buy
6. **Section 6 output** — Portfolio review (table from portfolio-reviewer skill)
7. **Today's date** — in YYYY-MM-DD format (e.g. `2026-02-23`)

---

## Output

A markdown file saved at:
```
Weekly Brief Updates/brief-YYYY-MM-DD.md
```

Where `YYYY-MM-DD` is today's date.

---

## Markdown Format

Assemble the file in this exact structure:

```markdown
# Weekly Investment Brief — YYYY-MM-DD

> Generated by the Weekly Investment Brief agent. US-focused. Age 29, higher risk profile, growth/retirement goal.

---

## 1. Market Analysis

[Section 1 content — bullet points, index performance, ticker data]

---

## 2. Geopolitical and Macro Context

[Section 2 content — what to watch, Fed, trade, geopolitical items]

---

## 3. Trends and Risk

[Section 3 content — trends, risks, catalysts, volatility outlook]

---

## 4. Stock Recommendations

[Section 4 content — table of ticker | rationale | risk]

---

## 5. When to Buy

[Section 5 content — entry conditions, timing guidance, DCA notes]

---

## 6. Portfolio Review

[Section 6 content — table from portfolio-reviewer: ticker | action | reasoning]

---

## 7. Summary

**Key takeaways for the week:**
- [Synthesize the 2–3 most important action items from sections 1–6]
- [Any urgent portfolio actions]
- [Top watch item for the week]

---

*Brief generated on YYYY-MM-DD. Data sourced via web search. Always verify prices before trading.*
```

---

## Steps to Execute

1. Construct the full markdown string by interpolating all section outputs into the template above.
2. Replace all instances of `YYYY-MM-DD` with today's actual date.
3. Ensure the `Weekly Brief Updates/` directory exists (create it if it does not).
4. Use the **Write** tool to save the file to `Weekly Brief Updates/brief-YYYY-MM-DD.md`.
5. Confirm the file was written and report the file path to the user.

---

## Formatting Rules

- Use `##` (H2) for each section heading.
- Use `###` (H3) for sub-sections within a section if needed.
- Use bullet points (`-`) for list items within sections.
- Preserve any tables returned by portfolio-reviewer (ticker | action | reasoning) and stock recommendations (ticker | rationale | risk) as markdown tables.
- Keep the horizontal rule (`---`) separators between sections for readability.
- Do not truncate any section content — include everything returned by prior steps.

---

## Failure Handling

- **`Weekly Brief Updates/` directory does not exist:** Create it with the Write tool before saving the file (the Write tool creates parent directories automatically).
- **Write tool fails:** Print the full assembled markdown brief to the terminal so no content is lost. Inform the user that the file could not be saved and display the content for manual saving.
- **Missing section output:** Include the section heading with a note: `*Data unavailable for this section.*` — do not skip the section entirely.
