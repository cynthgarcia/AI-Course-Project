# User profile — defaults

These are the starting preferences for Your Life Curator. Every item is editable in
**Settings**; the code defaults live in `src/lib/data/defaults.ts`.

## Location & schedule
- Home: Parsons Green / Fulham, London (no exact address stored or needed).
- Office: Windmill Street, Soho. In the office **Tuesday–Thursday**.
- Monday/Friday location is **not assumed** — travel estimates use the longer of home or office.
- Transport: walking and public transport. Driving is never assumed.
- Priority areas: Soho, Covent Garden, Fitzrovia, West End, South Bank, Chelsea, Fulham, Parsons Green (a mild boost, never a restriction).
- Timezone: Europe/London. Primary calendar: Google Calendar (integration not built yet).

## Budget
- £1,500/month activity budget — **a ceiling, not a target**.
- Estimated, planned and actual spending are tracked separately; unknown ≠ free.
- Trip transport and accommodation count against the budget by default (toggle in Settings).
- Foreign-currency amounts are only converted with a rate the user enters.

## Planning
- Main horizon 7–14 days; standout events up to 6 weeks ahead; trips up to ~3 months ahead.
- Weekly digest preference: Thursday afternoon (15:00), Europe/London — not automated yet.
- Gentle intentions (no streaks, no guilt): one fun thing a week, one new experience a month.
